# Manim Animations for tanFlux

This repository contains the Python source code used to generate mathematical and educational animations for the [tanFlux YouTube Channel](https://www.youtube.com/@tanflux). All animations are created using the [Manim](https://www.manim.community/) engine.

## 📂 Repository Structure

To ensure old scenes remain intact as the library updates, the code is organized by individual video or topic:

```text
manim-animations/
├── 01_Asymptotic_Notation/
│   └── asymptotic_notation.py 
    └── asymptotic_reels.py         
├── music/                  
│   └── .gitkeep
├── .gitignore              # Ignores large media and audio files
├── requirements.txt        # Pinned Manim version and dependencies
└── README.md
